# SimpleCode

开源桌面 AI 编程助手：可连接在线模型、下载本地 GGUF、组合多模型（视觉 / 摘要 / 代码 / 规划），并支持图片等多模态能力。

## 环境

- Windows
- [Node.js](https://nodejs.org/) 18+

## 运行

```bash
npm install
npm start
```

或双击 `启动.bat`（首次会自动安装依赖）。

模型权重请自行放到 `models/`（`.gguf` 文件不会进仓库）。API Key、会话等保存在本机 `%APPDATA%\SimpleCode`，不会写进源码。

## 功能概要

- 在线 API 与本地 GGUF 推理
- 模型组合：主模型 + 视觉 / 摘要 / 代码 / 规划辅助槽
- 图片识别（本地视觉运行时，不把原图发给不支持视觉的模型）
- 技能（`.simple`）与规则、人设
- 中英界面
